# WikiExplorer – Wikipedia Search App
WikiExplorer is a fast and simple Wikipedia search application designed to work smoothly on both mobile devices and desktop computers. It is built using pure JavaScript, HTML5, CSS3, Bootstrap5, and the Wikipedia REST API.

The app allows users to search any topic and instantly view article titles, short summaries, and direct links to full Wikipedia pages. The interface is clean, user‑friendly, and fully responsive, making it easy to explore information quickly.

# Features

Search any topic using the Wikipedia REST API

Instant results with titles, descriptions, and links

Clean and responsive UI built with Bootstrap

Works on both mobile and desktop

Lightweight and fast JavaScript application
# Tech Stack

WikiExplorer demonstrates API integration, DOM manipulation, and responsive UI design.
